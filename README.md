# Presentation Deck Guide

A small, practical toolkit for developers and technical teams who end up building presentations more often than their job description admits: sprint reviews, architecture walkthroughs, investor updates, conference talks, onboarding decks.

This repo has three parts:

- [`guide.md`](./guide.md) — the full write-up on what makes a technical presentation work
- [`templates/slide-outline-template.md`](./templates/slide-outline-template.md) — a fill-in-the-blank outline for structuring a deck before you touch a slide tool
- [`checklist.md`](./checklist.md) — a short pre-presentation checklist

## Why this exists

Most of the time spent building a deck goes into fighting the slide tool instead of the content. None of this is about making slides prettier. It's about making sure the time spent building a deck goes toward the argument, not the formatting.

## Contributing

If you have a template, checklist item, or diagramming convention that's worked well for your team, PRs are welcome.
